# Baqyla — лендинг

Одностраничный сайт Baqyla Security (видеонаблюдение, Уральск) с калькулятором:
клиент отмечает камеры на плане объекта (дом / бизнес / хозяйство), выбирает архив и длину кабеля,
получает предварительную смету и отправляет её в WhatsApp.

Без сборки: чистые HTML/CSS/JS.

- `index.html` — страница
- `assets/app.js` — калькулятор; **цены — в объекте `PRICE` в начале файла**, планы — в `PLANS`, комплекты — в `KITS`
- `assets/styles.css` — стили

Выбор в калькуляторе сохраняется в браузере (`localStorage`, ключ `baqyla-calc-v1`) — после перезагрузки клиент продолжает с того же шага.
«Поделиться расчётом» даёт ссылку вида `?obj=home&cams=1.2.3.4&days=14&cable=15` (номера камер — как на схеме);
на опубликованном сайте эта ссылка уходит и в сообщение WhatsApp, чтобы менеджер открыл ту же схему.

Цены и комплекты совпадают с CRM (`baqyla-crm/src/lib/seed.ts`).

## Локально

Открыть `index.html` в браузере, или:

```sh
python3 -m http.server 5191
# http://localhost:5191
```
